Quyền Truy Cập Camera

            
Cách bật "Luôn cho phép" không bị hỏi lại

          

        

        
      


      
      

        
        

          

            🍎
            Trên Safari (iPhone / iPad)
          

          
    
            
  1. Nhìn lên thanh URL Safari, bấm vào biểu tượng aA ở góc trái.
    2. 
            
  2. Chọn Cài đặt trang web (Website Settings).
    3. 
            
  3. Tại mục Camera, chọn Cho phép (Allow) thay vì Hỏi.
    4. 
          

        


        
        

          

            🌐
            Trên Chrome / Cốc Cốc (Điện thoại & PC)
          

          
    
            
  1. Bấm vào biểu tượng Cài đặt / Ổ khóa 🔒 bên trái thanh địa chỉ URL.
    2. 
            
  2. Chọn Quyền đối với trang web (Permissions).
    3. 
            
  3. Chuyển mục Máy ảnh (Camera) sang Luôn cho phép (Always Allow).
    4. 
          

        


        
        

          

            💻
            Trên Safari MacBook / iMac
          

          

            Vào menu Safari (trên cùng màn hình) ➜ Cài đặt cho trang web này... ➜ Mục Camera chọn Cho phép.
